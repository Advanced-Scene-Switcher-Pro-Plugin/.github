## 🚀 Overview
Advanced Scene Switcher Pro for Windows is a plugin that runs inside OBS Studio and takes the manual work out of live production. Instead of clicking scenes yourself, you build rules that watch for conditions — an active window, a running process, the time of day, audio levels, or a hotkey — and let the advanced scene switcher change scenes for you. This OBS advanced scene switcher plugin turns repetitive switching into reliable, hands-free automation so you can focus on your stream or recording.

## ✨ Features
- **Condition-based switching** — Trigger scene changes from the active window, running programs, idle time, media state, and more.
- **Macro editor** — Chain conditions and actions together to build advanced automation flows.
- **Hotkey and manual overrides** — Keep full control by mixing automatic rules with manual triggers.
- **Sequence and timing control** — Add delays, cooldowns, and ordered transitions between scenes.
- **Free and open source** — Use, inspect, and extend the plugin without any license fee.

## 📥 Installation
1. Click the **Download** button above to get the latest Advanced Scene Switcher Pro plugin package for Windows.
2. Close OBS Studio, then run the downloaded installer (or copy the plugin files into your OBS Studio plugins folder) and follow the on-screen steps.
3. Open OBS Studio and select **Tools → Advanced Scene Switcher** from the menu bar, where the plugin now appears.

## 🎯 Getting Started
1. Launch OBS Studio and open your usual profile and scene collection.
2. Go to **Tools → Advanced Scene Switcher** to open the plugin window.
3. Create your first rule by choosing a condition (for example, a specific active window) and the scene it should switch to.
4. Enable the switcher and test the rule by triggering its condition.

## ❓ FAQ
**Is Advanced Scene Switcher Pro free?**
Yes. It is a free, open-source plugin for OBS Studio, so there is no purchase or subscription required.

**Which versions of Windows are supported?**
It runs on Windows 10 and Windows 11 (64-bit) wherever a supported version of OBS Studio is installed.

**Is my data secure?**
The plugin runs locally inside your own OBS Studio installation and stores its rules with your OBS configuration, so nothing is sent to an external service by the plugin itself.
